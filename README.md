# Creative Scrolling Interview Website — Mirza Aadil Ali Baig

A fully filled, animated, multi-section interview portfolio website.

## Live website link (usable anywhere)

After pushing this repo to GitHub, enable **GitHub Pages** and your live link will be:

`https://<your-github-username>.github.io/My-Profile/`

Example format: `https://username.github.io/My-Profile/`

## Sections included

- Hero + interview snapshot + quick stats
- Professional summary + focus areas
- Education timeline
- Technical skill universe
- Internship experience
- Project showcase
- Certifications + leadership activities
- Contact section + soft-skill chips

## Animations included

- Animated gradient background blobs
- Pop / slide / fade-in reveal animations on scroll
- Hover interactions on cards and links
- Theme switcher (dark/light) with local storage

## Run locally

```bash
python3 -m http.server 4173
```

Open: `http://localhost:4173`

## Edit content

All portfolio data is in the `profile` object inside `script.js`.
