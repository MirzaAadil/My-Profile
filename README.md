# Creative Scrolling Interview Website — Mirza Aadil Ali Baig

A creative, multi-section scrolling interview website designed to feel like a modern portfolio story.

## Highlights

- Full-page scrolling sections (hero, about, skills, experience, projects, achievements, contact)
- Animated gradient background blobs
- Pop/slide/fade reveal animations while scrolling
- Recruiter-friendly navigation bar with section anchors
- Interactive contact CTAs (phone, email, LinkedIn)
- Theme toggle (dark by default + light mode support)

## Run

```bash
python3 -m http.server 4173
```

Open: `http://localhost:4173`

## Editing content

All resume data is controlled from the `profile` object in `script.js`.
